# Проверка созданного навыка

Дата: 2026-10-14. Версия навыка: 1.0.2. Среда: Linux, Node.js 24.19.0, Playwright 1.62.1, **Microsoft Edge 155.0.4283.45**, axe-core 4.14.0, Pillow 12.3.0.

Edge подготовлен из официального пакета packages.microsoft.com; размер и SHA-256 сверены с индексом Microsoft. Это отдельный Edge облачной среды, не подключение к браузеру/дискам компьютера пользователя. Политика: только Edge, без запасного браузера.

Пакет зарегистрирован в `.agents/skills/stroykerbox-site-audit` этого репозитория. Для обнаружения навыка нужна новая сессия в данном проекте. Текущий чат не переобъявляет свои инструменты автоматически.

## Выполнено

- Интеграционный тест настоящего Microsoft Edge: четыре включённые страницы, порядок 2550 → 390 → 767 → 768 px, выборка товаров и продолжение частичного обхода.
- Проверены raw href (относительный, абсолютный, protocol-relative), количество h1, низкий контраст поля, вес картинки и одинаковые байты при разных URL.
- POST, HTML submit/native submit и GET-действие cart/add не достигли сервера локального стенда.
- Инпут принял и очистил вымышленный email; autosave и отправка заблокированы, фокусное состояние сохранено.
- Чеклисты содержат только confirmed, а не автоматические кандидаты.
- Отдельный тест ссылок: проверен товар за пределами визуальной выборки; 404 — кандидат; 403 — неизвестная доступность; редирект на мутацию заблокирован; HEAD 405 заменён безопасным GET.
- Все пять автоматических тестов завершились успешно: основной браузерный тест, отчёт, ссылки, запрет других браузеров, отсутствие fallback после ошибки Edge. Python-файлы и JS-синтаксис проверены.
- На двух локальных тестовых растровых изображениях создан и просмотрен контактный лист; ресайз найден как похожий кандидат. SVG честно отмечен как не декодированный Pillow. Внешняя уникальность не заявлена.

## Ограничения пробного запуска

Предыдущий пробный запуск версии 1.0.0 на tsk-market.ru при 2550 px остановился на сетевой блокировке. `auditComplete=false`, визуальные проверки/инпуты/содержание изображений не выполнены. `audit-results/tsk-market-2026-10-14` сохраняет исторический manifest, coverage и два пустых чеклиста подтверждённых ошибок. Этот результат не переименован в результат Edge. После требования «всегда Edge» выполнены локальные тесты версии 1.0.1 только в Edge; сетевое ограничение целевых сайтов не изменено.

Веб-инструмент получил текст главной, страницы товара, «О нас», «Контакты» и «Доставка»; это не считается браузерным/визуальным аудитом. Адрес товара `/catalog/product/…` подтверждён и включён в правила выборки.

Документация box7.nastroyker.ru не получена. Для stroybaza-samara.ru/api/v1/docs/ сетевой шлюз вернул 403 на CONNECT до обращения к целевому сайту. Механизм авторизации и корректность предоставленных данных не проверены. Учётные данные не входят в файлы или архив.
