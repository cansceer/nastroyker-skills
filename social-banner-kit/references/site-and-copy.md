# Получать фирменные материалы и содержание

## Источники и ассеты

- Начинать с указанного сайта: главная, шапка/подвал, контакты, каталог, выбранные карточки товаров. Перейти по каталоговым категориям, когда товары надо выбрать самостоятельно. Ориентироваться на запрос, ассортимент и выразительность сцены, а не брать несколько соседних товаров из одной категории.
- Получать оригинальные файлы логотипа из шапки, подвала, SVG sprite или inline SVG. Сохранять фирменные пропорции, цвета и охранное поле. Не типографировать название бренда вместо логотипа и не перерисовывать его AI. Если доступен только маленький логотип, искать его крупную официальную версию на том же сайте.
- Читать связанные CSS и действующие переопределения. Получать семейство и начертание фактически используемого заголовка/основного текста и соответствующие font-файлы. Проверить поддержку кириллицы. Отличать обычный/курсивный и Regular/Bold; не включать искусственное утолщение вместо доступного фирменного начертания.
- Разрешить только оригинальные шрифты этого сайта. WOFF/WOFF2 допустимы для HTML; при необходимой конвертации менять контейнер, сохраняя саму гарнитуру. Проверять `document.fonts.ready` и отсутствие fallback перед растрированием.
- Использовать `srcset`, большие фотографии карточки, галерею или исходный URL товара. Не заменять товар похожим найденным в поиске. Если несколько кадров товара, выбирать доступный ракурс с точными видимыми сторонами упаковки.
- Сохранять для каждого ассета URL страницы, URL файла и роль: логотип, лицо, фронт/бок упаковки, товар, фон или стилевой референс. В многокадровом запросе генератору обозначать эти роли по индексам.
- Собирать исходники в папке текущего задания. Не перечислять и не читать пользовательские файлы других проектов/разговоров. При недостатке материалов выбирать композицию с доступными точными ассетами.

## Текст по умолчанию

Строить короткую иерархию:

1. Оригинальный логотип и, если нужно, понятное обозначение деятельности/основной тезис сайта.
2. Один заголовок и один короткий тезис или до двух компактных преимуществ, только когда остаётся ясность и место.
3. Основной телефон с сайта и короткий читаемый домен. Добавлять простые согласованные иконки, когда они помогают различить контакты; не использовать декоративные значки ради заполнения.

Если пользователь дал собственный текст, он важнее автоматического шаблона. Не добавлять слоган/CTA/контакты вопреки явному «только этот текст». Если телефона на сайте нет, не придумывать его. Если телефонов несколько, выбрать подтверждённый общий номер из шапки/контактов, не случайный номер филиала. Физический адрес добавлять только по запросу или если он важен для задачи; «адрес сайта» означает URL/домен.

Проверять текст до сборки и после экспорта. Для телефона сохранить цифры и смысл форматирования; для домена убрать необязательный протокол, но сохранить нужный поддомен. Не использовать ложные обещания из придуманных промптов.

## Точная типографика

- Использовать 1–2 гарнитуры сайта; не более 3 размеров набранного текста на одну адаптацию. Размеры могут меняться между площадками при сохранении иерархии.
- Выбирать размеры по конечной видимой области и отображению после уменьшения. Сначала измерять текст реальным шрифтом, затем выбирать переносы и ширины блоков.
- Согласовать левые края/центры осмысленных блоков, базовые линии контактов и размеры иконок. Учитывать оптические выступы букв, а не только формальные bounding boxes.
- Не растягивать шрифт по одной оси, не использовать случайный трекинг для заполнения ширины. Не делать дополнительный микрокегль ради лишних фактов.
- Если встроенный генератор исказил буквы, не считать это финалом: собирать точную типографику отдельно в редактируемой раскладке из настоящих font-файлов.
