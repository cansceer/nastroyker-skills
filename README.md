# Nastroyker Skills

Навыки и плагины для Codex.

## Плагины

| Плагин | Назначение |
|---|---|
| `social-banner-kit` | Создание и адаптация баннеров для соцсетей. |
| `stroykerbox-site-audit` | Аудит сайтов на StroykerBox в Microsoft Edge. Выдаёт два чеклиста и не вносит изменения на сайт. |

## Установка в Codex Desktop

1. Откройте **Plugins → Add marketplace**.
2. Укажите источник `cansceer/nastroyker-skills` и Git ref `main`.
3. Оставьте **Выборочные пути** пустыми. Манифест маркетплейса находится в `.agents/plugins/marketplace.json`; выборочная загрузка только папки плагина скроет его.
4. Нажмите **Добавить маркетплейс**, затем в каталоге плагинов установите `stroykerbox-site-audit`.

## Запуск аудита

Начните новый чат и напишите:

> Проведи аудит https://tsk-market.ru/ по профилю tsk-market. Только проверка, без правок и отправки форм.

Подробные правила аудита — в [инструкции навыка](.agents/skills/stroykerbox-site-audit/SKILL.md). Исходные файлы сайта в репозиторий не входят.
