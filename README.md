# Nastroyker Skills

Навыки для ChatGPT и плагины для Codex. **В ChatGPT используется навык, в Codex — плагин, в состав которого входит навык.** Репозиторий хранит их исходники; установка плагина в Codex и обновление личного навыка в ChatGPT выполняются отдельно.

## Плагины

| Плагин | Назначение |
|---|---|
| [`social-banner-kit`](#комплекты-баннеров-для-соцсетей) | Комплекты обложек ВКонтакте, RUTUBE и YouTube по фирменному стилю бренда: согласование направления, отдельная композиция для каждой площадки, проверка финалов. Figma — по запросу. |
| `stroykerbox-site-audit` | Аудит сайтов на StroykerBox в Microsoft Edge. Создаёт чеклист задач с прямыми ссылками и не вносит изменения на сайт. |

## Установка в Codex Desktop

1. Откройте **Plugins → Add marketplace**.
2. Укажите источник `cansceer/nastroyker-skills` и Git ref `main`.
3. Оставьте **Выборочные пути** пустыми. Манифест маркетплейса находится в `.agents/plugins/marketplace.json`; выборочная загрузка только папки плагина скроет его.
4. Нажмите **Добавить маркетплейс**, затем в каталоге установите нужный плагин: `social-banner-kit` для обложек или `stroykerbox-site-audit` для аудита сайтов.

## Комплекты баннеров для соцсетей

**ChatGPT:** навык «Комплекты баннеров для соцсетей». **Codex:** плагин `social-banner-kit`, содержащий одноимённый навык. Он создаёт и исправляет рекламные обложки по сайту, логотипу, брендбуку, фотографиям товаров и персонажей. Подходит разным брендам: стиль и материалы исследуются заново для каждого проекта.

### Как проходит работа

1. Исследование бренда и материалов, визуальный разбор трёх встроенных референсных проектов. Из референсов берутся композиционные приёмы, без копирования чужой айдентики.
2. Разработка и показ конкретных визуальных направлений. Пользователь утверждает направление до сборки финалов; этот этап можно явно попросить пропустить.
3. Отдельная композиция для каждой площадки с общей рекламной идеей. Один комплект для трёх площадок — три финальных файла; по умолчанию создаётся один комплект.
4. Проверка идеи, фирменного стиля и исполнения: иерархия, читаемость, поля, лица и распознаваемые части товаров в безопасных областях, качество обработки и изображений. Проверяются экспорты при реальном размере показа, с масками интерфейса и при 100%. Технический скрипт проверяет геометрию и свойства файлов; художественное качество требует отдельного визуального ревью и самостоятельного исправления дефектов.

### Как поставить задачу

В ChatGPT выберите навык по имени. В Codex после установки плагина используйте `$social-banner-kit`. Укажите сайт, цель, аудиторию, главный посыл, точный текст, материалы бренда и ограничения. Можно писать свободно: готовый [шаблон задания находится в начале инструкции навыка](plugins/social-banner-kit/skills/social-banner-kit/SKILL.md).

Пример для Codex:

```text
Используй $social-banner-kit.
Создай 1 комплект обложек для ВКонтакте, RUTUBE и YouTube.
Проект: <сайт>. Цель: <цель>. Аудитория: <аудитория>.
Главный посыл: <посыл>. Точный текст: <текст и адрес сайта>.
Логотип, фирменный стиль и фотографии приложены.
Обязательные условия: <ограничения>.
```

### Что выдаётся

По умолчанию — готовые **PNG/JPEG** в форматах площадок. Баннеры не публикуются в аккаунты соцсетей автоматически.

**Figma включается только по явному запросу:** например, «Дополнительно нужен редактируемый макет в Figma со слоями и текстами». Тогда результат — ссылка на Figma и готовые изображения; при просьбе «только Figma» выдаётся одна ссылка. Требуются доступная интеграция Figma, права на целевой файл и нужные шрифты. Тексты остаются текстовыми слоями, графика и исходные SVG — отдельными элементами, фотографии и сложная ретушь — растровыми ассетами или фотогруппами. Возможность редактировать макет не означает редактируемость каждой детали фотографии.

В режиме Figma финальные изображения экспортируются из тех же проверенных фреймов. Последующие правки вносятся в мастер-макет с сохранением утверждённых решений и повторной проверкой затронутых адаптаций.

## Запуск аудита

Начните новый чат и напишите:

> Проведи аудит https://tsk-market.ru/ по профилю tsk-market. Только проверка, без правок и отправки форм.

Подробные правила аудита — в [инструкции навыка](.agents/skills/stroykerbox-site-audit/SKILL.md). Исходные файлы сайта в репозиторий не входят.

## Арт-директор Codex

Профиль проектного агента находится в `.codex/agents/design-director.toml`. Он доступен, когда этот репозиторий открыт в Codex, и использует навыки, доступные родительской сессии. Для обложек установите плагин `social-banner-kit` из маркетплейса выше.

Чтобы сделать профиль личным и доступным в других проектах, скопируйте файл в `~/.codex/agents/design-director.toml`.
