# Профиль StroykerBox

Документация пользователя: https://box7.nastroyker.ru/api/v1/docs/. В сессии создания документация не получена. Нельзя утверждать, что она закрыта авторизацией: наблюдалась ошибка доступа, причина не подтверждена. Не переносить устройство другой CMS на StroykerBox.

Дополнительный адрес: https://stroybaza-samara.ru/api/v1/docs/. Также не получен из среды создания: сетевой запрос остановился до соединения с сайтом. Учётные данные, переданные в чате для проверки, в пакет не сохранены; их корректность/механизм авторизации не проверены.

Контакты, ЛК, корзина, каталог, формы, контейнеры, шапка, подвал и слайдеры используют встроенные стили. Права изменения неизвестны. Работа с опубликованным HTML не означает доступ к шаблонам/API/FTP.

Аудитируй только опубликованный сайт: исходную и отрисованную разметку, а также CSS/JS, которые браузер загрузил с сайта. Не ищи локальные файлы на компьютере пользователя, в OneDrive или каталогах проекта. Если нужный сетевой файл недоступен, отметь его как непроверенный; не делай выводов о его содержимом.

| Происхождение | Исполнитель в отчёте | Как формулировать |
|---|---|---|
| Текст, адрес назначения, alt, картинка, метатеги | Пользователь | Изменить конкретное поле/блок в CMS; если место неизвестно, так и указать |
| Отступ, шрифт, цвет, переполнение | Codex, потенциально | Привести селектор и правило из загруженного CSS, предложить точечное изменение; возможность правки в CMS не предполагать |
| Поведение, ошибка скрипта | Codex, потенциально | Привести URL подключённого JS, строку/фрагмент и наблюдаемое действие; не исполнять код отдельно |
| HTML/серверный шаблон, h1, системная ссылка | Пользователь | Нужна настройка/шаблон CMS; CSS не изменяет семантику |
| Защищённый компонент CMS | Пользователь, ограничение CMS | Указать проблему и необходимость проверки разрешённого способа изменения |
| Неизвестный владелец | Определить по причине | Не обещать исправление в несуществующем файле; обозначить условие |

Паспорт исключения: `id`, URL/шаблон, селектор/атрибут, конкретное правило, причина, кто/на каком основании утвердил, дата, допустимая область. «Это CMS» — недостаточное исключение. Нельзя скрывать ошибки пользовательской части из-за общего системного происхождения страницы.

Не добавлять глобальные reset, общие `button`, `input`, `h1` и безусловные `!important` как стандартное предложение. Для следующего навыка исправлений понадобятся разрешённые файлы, контекст системных стилей, тестовый стенд, способ отката и проверки всех затронутых шаблонов. Этот навык только записывает конкретные потенциальные исправления.
